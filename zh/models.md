# 可用模型列表

本页汇总当前主流 AI 厂商开放的模型列表与能力说明，方便统一查询与对接。模型报价请查看[模型报价](/zh/model-pricing)。

## 模型说明

- 系统默认接入各 AI 厂商的**最新可用模型**
- 不同 API Key 绑定不同厂商分组
- **模型可用性取决于分组授权情况**
- 所有模型调用均保持与官方 API 高度兼容

## 可用模型列表（每日更新）

| 模型名称 | 类型 | 特点描述 |
| :--- | :--- | :--- |

| **gpt-5.4** | 强交互助理 | 毫秒级原生音视频流式通话，完美识别语气与情绪变化。 |
| **gpt-5.4-mini** | 轻量效率工具 | `1.4s` 极速响应，超低成本完成日常交互与内容提炼。 | 
| **gpt-image-2** | 高精视觉中枢 | 擅长极速生成高保真图像，深度解析复杂物理与科研级视觉数据。 |
